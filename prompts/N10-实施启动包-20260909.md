## B. 适配器层设计（基于 3 个实测源 + 4 复用源）

### 公共类型（`apps/readest-app/src/app/opds/adapters/types.ts`）

```ts
export interface SearchResult {
  id: string;          // 源内唯一 id
  title: string;
  author?: string;
  description?: string;
  cover?: string;      // URL
  source: string;      // 对应 catalog id
  adapterType: AdapterType;
}

export interface BookDetail extends SearchResult {
  contentUrl?: string; // 全文 URL（epub / html / pdf）
  format?: 'epub' | 'html' | 'pdf' | 'txt';
  license?: string;    // SPDX 或 'publicdomain'
  language?: string;   // ISO 639-1
}

export interface SourceAdapter {
  type: AdapterType;
  search(query: string, page?: number): Promise<SearchResult[]>;
  getBook(id: string): Promise<BookDetail>;
}

export type AdapterType = 'opds' | 'mediawiki' | 'archive-advancedsearch' | 'custom-http';

// 内置源注册表
export const ADAPTER_REGISTRY: Record<string, () => SourceAdapter> = {
  'opds': () => new OpdsAdapter(),
  'mediawiki': () => new MediaWikiAdapter(),
  'archive-advancedsearch': () => new ArchiveAdvancedSearchAdapter(),
  'custom-http': () => new CustomHttpAdapter(),
};
```

### 4 个适配器签名

| 适配器 | 用源 | search 端点 | getBook 端点 |
|---|---|---|---|
| `OpdsAdapter` | readest 复用的 4 个（Standard Ebooks / ManyBooks / Feedbooks / 等等） | OPDS 1.2 acquisition feed | OPDS entry |
| `MediaWikiAdapter` | zh.wikisource / en.wikisource | `?action=query&list=search&srsearch=…&format=json` | `?action=parse&page=…&format=json` |
| `ArchiveAdvancedSearchAdapter` | archive.org | `/advancedsearch.php?q=mediatype%3A(texts)+AND+licenseurl%3A(*publicdomain*)&output=json&rows=…` | `/metadata/{id}` |
| `CustomHttpAdapter` | 兜底（用户自定义 URL，N11a 用） | 配置 URL 模板 + 解析器 | 同上 |

### CatalogManager.tsx 改动策略

- 保留 4 个 readest 复用源（id 命名一字不改）
- 新增 3 个内置源：
  - `wikisource-zh` → adapterType: `mediawiki`，URL `https://zh.wikisource.org/w/api.php`，group: `popular`
  - `wikisource-en` → adapterType: `mediawiki`，URL `https://en.wikisource.org/w/api.php`，group: `popular`
  - `archive-publicdomain` → adapterType: `archive-advancedsearch`，URL `https://archive.org/advancedsearch.php?...`，group: `publicdomain`
- 每个新源加 `adapterType` 字段
- DOAB 不入 N10（实测不可达）
